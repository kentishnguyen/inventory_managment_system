# Inventory Management Application
This app is designed to manage and track inventory for a packaging supply store.

## Problem
The owner needs a simple way to track products, quantities, stock changes and order made

## Requirements
Following are the requirements for the software

### Core features 
- Add/delete products
- Add/delete customers (name, address and phone number)
- Automatically update stocks when new shipment arrives
- View inventory
- Search/filter products also showing stocks of those products
- Search/filter customers
- Record transactions

### Later features
- Different employee permissions
- Reports
- Supplier management
- Financial reports
- Make suggestions
